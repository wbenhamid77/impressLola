# 🏆 Background Thématique Maroc - CAN 2025

## 🌟 Vue d'ensemble

Le background de la page de login a été entièrement repensé pour créer une expérience immersive qui célèbre le Maroc et la Coupe d'Afrique des Nations 2025. Il combine des éléments visuels riches, des animations fluides et une identité visuelle cohérente.

## 🎨 Éléments du background

### 🖼️ Images d'arrière-plan
- **Paysage marocain** : Vues panoramiques du Maroc avec animation de pulsation
- **Stade de football** : Représentation des stades modernes avec animation inverse
- **Drapeau marocain** : Élément flottant avec animation douce

### 🎭 Motif géométrique marocain
- **20 éléments circulaires** : Disposition stratégique sur toute la page
- **Animation de rotation** : Rotation continue à différentes vitesses
- **Couleur dorée** : Représentation de l'or marocain
- **Opacité subtile** : Effet de profondeur sans surcharger

### 🌟 Éléments flottants thématiques
1. **🏆 Trophée CAN** : Trophée doré avec effet de lueur
2. **🌍 Carte d'Afrique** : Représentation du continent africain
3. **🇲🇦 Drapeau marocain** : Drapeau officiel du Maroc
4. **⚽ Ballon de football** : Ballon tournant en continu
5. **⭐ Étoile** : Étoile scintillante (symbole de l'étoile marocaine)
6. **🌴 Palmier** : Palmier qui se balance (symbole du Maroc)

### ✨ Particules animées
- **15 particules dorées** : Montent depuis le bas de l'écran
- **Animation continue** : Mouvement fluide et naturel
- **Effet de profondeur** : Créent une atmosphère dynamique

### 🌊 Vagues animées
- **3 vagues superposées** : Mouvement horizontal continu
- **Délais différents** : Créent un effet de profondeur
- **Couleur dorée** : Cohérent avec le thème

### ⚽ Grille de football stylisée
- **10 lignes horizontales** : Représentent les lignes de terrain
- **Animation verticale** : Mouvement vers le haut
- **Couleur dorée** : Effet subtil et élégant

### 🏟️ Éléments de stade
- **8 projecteurs** : Simulent l'éclairage d'un stade
- **Animation de pulsation** : Effet d'éclairage réaliste
- **Positionnement stratégique** : Créent l'ambiance d'un stade

## 🎯 Thème visuel

### 🎨 Couleurs principales
```css
--morocco-red: #c1272d      /* Rouge officiel Maroc */
--morocco-green: #006233    /* Vert officiel Maroc */
--accent-gold: #ffd700      /* Or pour les accents */
```

### 🌈 Dégradés utilisés
- **Gradient Maroc** : Rouge vers vert (couleurs officielles)
- **Gradient doré** : Or vers jaune doré
- **Gradient coucher de soleil** : Orange vers doré

## 🎬 Animations

### 🔄 Animations principales
1. **Float** : Mouvement de flottement vertical avec rotation
2. **Pulse** : Effet de pulsation pour les images
3. **Spin** : Rotation continue pour le ballon
4. **Glow** : Effet de lueur dorée
5. **Wave** : Mouvement de vagues
6. **Pattern-rotate** : Rotation des motifs géométriques
7. **Stadium-light** : Pulsation des projecteurs
8. **Grid-move** : Mouvement de la grille
9. **Star-twinkle** : Scintillement des étoiles
10. **Palm-sway** : Balancement des palmiers

### ⏱️ Délais d'animation
- **Éléments flottants** : Délais de 0s à 5s
- **Particules** : Délais de 0s à 28s
- **Motifs géométriques** : Délais de 0s à 38s
- **Vagues** : Délais de 0s, 2s, 4s
- **Projecteurs** : Délais de 0s à 3.5s
