📅 Formulaire de Réservation

Annonce sélectionnée:

Le composant Angular de réservation sera affiché ici avec l'ID de l'annonce sélectionnée.

🔧 Comment ça fonctionne dans Angular :

1. Dans le composant parent (liste des annonces) :


// Template HTML
<button (click)="reserverAnnonce(annonce.id)">Réserver</button>

// Composant TypeScript
reserverAnnonce(annonceId: string): void {
  this.router.navigate(['/reservation'], { 
    queryParams: { annonceId: annonceId } 
  });
}

2. Dans le composant de réservation :


// Template HTML
<app-reservation [annonceId]="annonceId"></app-reservation>

// Composant TypeScript
export class ReservationComponent implements OnInit {
  @Input() annonceId: string = '';
  
  ngOnInit(): void {
    if (this.annonceId) {
      this.reservationForm.patchValue({ annonceId: this.annonceId });
    }
  }
}

3. Dans le routing :


const routes: Routes = [
  { path: 'reservation', component: ReservationComponent },
  { path: 'reservation/:annonceId', component: ReservationComponent }
];
