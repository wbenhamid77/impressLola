# 🇲🇦 Background Thème Maroc - Login CAN 2025

## 🌟 Vue d'ensemble

Le background de la page de login a été transformé pour célébrer le thème du Maroc en utilisant les couleurs officielles du drapeau marocain : rouge et vert. Ce design crée une ambiance authentique et patriotique pour la Coupe d'Afrique des Nations 2025.

## 🎨 Couleurs officielles du Maroc

### 🇲🇦 **Palette de couleurs**
```css
--morocco-red: #c1272d      /* Rouge officiel du drapeau marocain */
--morocco-green: #006233    /* Vert officiel du drapeau marocain */
--accent-gold: #ffd700      /* Or pour les accents et détails */
```

### 🌈 **Dégradés marocains**
- **Gradient principal** : Rouge vers vert (135°)
- **Gradient inverse** : Vert vers rouge (135°)
- **Gradient diagonal** : Rouge-vert-rouge (45°)
- **Gradient horizontal** : Rouge vers vert (90°)

## 🎨 Personnalisation

### 🔧 **Variables CSS**
Toutes les couleurs et animations sont personnalisables :

```css
:root {
  --morocco-red: #c1272d;
  --morocco-green: #006233;
  --accent-gold: #ffd700;
  --gradient-morocco: linear-gradient(135deg, var(--morocco-red) 0%, var(--morocco-green) 100%);
}
```

### 🎛️ **Contrôles d'animation**
- **Durée** : Ajustable via les variables CSS
- **Délais** : Personnalisables pour chaque élément
- **Opacité** : Contrôle de la visibilité
- **Position** : Placement flexible
